# Assignment 3.1 — Two-Page Website with Working Links

## Theory

The objective of this assignment is to understand how to create a simple two-page website and connect web pages using HTML hyperlinks. It also explains how to add a navigation bar and link to an external website.

### 1. Creating Two HTML Pages

Two HTML files, `index.html` and `about.html`, are created for the website.

- index.html: This is the home page of the website. It contains the website name, an introduction, and a navigation bar.
- about.html: This page contains information about the website, its purpose, or its creator.

### 2. Creating a Navigation Bar

A navigation bar helps users move between different pages of a website. In this assignment, the navigation bar contains two links: Home and About. These links make the website easier to navigate.

### 3. Using the Anchor Tag

The HTML `<a>` (anchor) tag is used to create hyperlinks. The `href` attribute specifies the destination of a link.

For example, a link to the home page points to `index.html`, while a link to the About page points to `about.html`. This allows users to navigate between the two pages.

### 4. Adding an External Link

An external link connects the website to another website, such as Google. The `target="_blank"` attribute opens the linked website in a new browser tab.

The `rel="noopener noreferrer"` attribute provides additional security and privacy by preventing the newly opened page from accessing the original page through `window.opener` and by suppressing referrer information.
